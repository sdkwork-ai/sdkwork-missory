# SDKWork Missory Workspace Skills

Repository-local agent skills live at `.sdkwork/skills/<kebab-name>/SKILL.md`.

Each skill directory may carry `references/`, `scripts/`, and `assets/` next to `SKILL.md`.
Skills are local extensions; they must not contradict `../sdkwork-specs/SOUL.md` or any
global standard in `../sdkwork-specs/`.

Canonical standards:

- `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`
