# SDKWork Missory Workspace Plugins

Repository-local installable agent plugins live at
`.sdkwork/plugins/<kebab-name>/.codex-plugin/plugin.json`.

Plugins are local extensions; they must not contradict `../sdkwork-specs/SOUL.md` or any
global standard in `../sdkwork-specs/`.

Canonical standards:

- `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`
